## Overview

Free VIN Generator is a fast, lightweight static site that helps people work with **17-character Vehicle Identification Numbers**. It serves used-car buyers checking a VIN, developers and QA engineers who need realistic test data, and anyone learning how VINs are structured.

Generated VINs are structurally valid (correct ISO 3779 check digit) and intended for **testing, development, and educational use** — not for registration, insurance, or any legal purpose.

## Features

### Tools
| Tool | Description |
|------|-------------|
| **VIN Generator** | Create random, structurally valid VINs with correct check digits |
| **VIN Decoder** | Decode any VIN into country, manufacturer, model year, and plant |
| **VIN Validator** | Check length, characters, and the ISO 3779 check digit |
| **Bulk VIN Generator** | Generate up to 1,000 VINs at once; export as CSV or TXT |
| **VIN QR Code Generator** | Turn a VIN into a downloadable, scannable QR code |
| **VIN Breakdown Visualizer** | See every VIN position mapped out in an interactive diagram |

### Content
- **Blog** — practical, in-depth guides on reading, checking, and understanding VINs
- **What is a VIN?** — a complete reference on VIN structure
- Light & **dark mode**, fully responsive, no external UI frameworks
