Buying parts, ordering oil, or checking a recall all depend on one thing: knowing which engine is actually in the car. Two versions of the same model can carry a four-cylinder or a V6, and guessing wrong wastes money. The VIN answers this. One specific character encodes the engine, and once you know where to look, you can read it off in seconds. Here is how.

## The Engine Lives in Position 8

A VIN has 17 characters, and the eighth one is the engine code. Count from the left: the first three are the manufacturer block, positions four through eight describe the vehicle, and position eight is set aside for the engine. It is a single letter or number that maps to a specific engine family: displacement, cylinder count, fuel type, and sometimes the emissions setup.

| Position | What it holds |
|---|---|
| 1-3 | Manufacturer and country |
| 4-7 | Model, body, restraints |
| **8** | **Engine code** |
| 9 | Check digit |
| 10 | Model year |
| 11-17 | Plant and serial |

That single character is why a VIN can tell a parts desk exactly which water pump or gasket set your car needs.

## The Code Is Brand-Specific

Here is the catch: there is no universal engine chart. Each automaker assigns its own meaning to the position-8 character, and the same letter means different things across brands. A "B" on a Honda is not the "B" on a Chevrolet.

Take a couple of examples to see the idea, not to memorize:

| VIN position 8 | Maker | Might mean |
|---|---|---|
| A | Brand X | 2.0L 4-cylinder |
| G | Brand X | 3.5L V6 |
| N | Brand Y | 1.8L turbo |

The exact table comes from the manufacturer for that model year. That is why the reliable move is to let a decoder read the maker's chart for you rather than trusting a generic list. ## Why the Engine Code Matters

Reading position eight is not trivia. It changes real decisions:

- **Parts.** Filters, belts, gaskets, and sensors differ by engine. The VIN's engine code is how a parts counter pulls the right one.
- **Fluids.** Oil capacity and spec can change between a four-cylinder and a V6 in the same model.
- **Recalls.** Some recalls apply only to a specific engine. Matching the code tells you if yours is affected. See [how to check open recalls by VIN](/blog/how-to-check-recalls-by-vin/).
- **Buying used.** A listing that says "V6" should match the VIN. If it does not, ask why before you pay.

In each case the engine code turns a vague description into a fact you can act on.

## How to Read It Step by Step

You can do this by hand with any VIN:

1. Write out the 17 characters and number them 1 to 17.
2. Find character number 8. That is your engine code.
3. Note the make and model year first (positions 1-3 and 10), because the code only makes sense in that context.
4. Look up that maker's engine chart for that year, or let a decoder do it.

## The Limit of Position 8

One honest caveat: the VIN gives the engine family, not every mechanical detail. It tells you the displacement and configuration the car left the factory with. It does not know if someone later swapped the engine, and it will not list horsepower trims or minor mid-year variants. For those, match the VIN's engine code against the door-jamb label or the build sheet. For most buying and parts decisions, though, position eight is exactly what you need.
